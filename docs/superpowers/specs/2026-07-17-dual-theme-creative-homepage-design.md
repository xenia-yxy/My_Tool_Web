# 双主题创作首页设计

## 目标

将公开首页从早期的个人网站 MVP 介绍页改为创作平台的视觉入口。首页不解释产品、不展示路线图、不堆叠功能卡片；用一个沉浸式舞台表达创作状态，并在下一屏提供进入已上线能力的入口。

## 已确认的内容

- 核心文案只保留：

  ```text
  干就完了，
  先做一坨屎
  ```

- 默认主题为白昼画布：白色背景、低饱和彩色图层、动态图片碎片。
- 提供夜间模式：深色高对比舞台、同一布局、不同色彩和发光边缘。
- 顶部只保留动态 Logo、主题切换、登录或进入工作台。
- 首屏不出现产品介绍、MVP、功能清单、说明性副标题或联系按钮。
- 滚动后展示男装、女装、IP 衍生、平台封面、创作画布等已上线能力。
- 动态 Logo 表现为生成中的叠片图标：静止呼吸、悬停重组、主题切换变色。
- 浮动 Agent 图使用 `/agent/bingou.png`；生产镜像必须携带 `public` 目录。

## 信息架构

### 顶部导航

- 左侧：无文字或极短文字的动态叠片 Logo，点击返回首页。
- 右侧：主题切换图标、登录图标或进入工作台图标。
- 不显示“联系”、个人库、副标题和普通文本导航。
- 顶部保持透明，仅在滚动到能力区后增加细边框与背景。

### 首屏

- 高度：至少一个视口，桌面和移动端都露出下一屏 8-12% 的内容。
- 主文案：居中偏左，固定大字号但不以 viewport 单位缩放；移动端自动换行且不截断。
- 背景：CSS 绘制的细网格、可拖动的图层线框、来自本地静态资源或已授权图片的少量视觉碎片。
- 不使用渐变球、bokeh、营销插画或悬浮说明卡片。
- 鼠标/触屏：图层根据指针产生轻微视差；`prefers-reduced-motion` 时禁用动画。

### 能力区

- 不使用四宫格营销卡片。改为一张横向、可滚动的创作轨道。
- 每个能力为一张带真实图片预览的画布节点：男装视觉、女装视觉、IP 衍生、平台封面、创作画布。
- 节点显示图标与短名称，不显示解释段落；点击直接进入对应工具。
- 节点具有明确尺寸、键盘焦点、加载占位与图片失败回退。

### Agent

- 保留右下角 Agent 入口，但使用 Bingou 图片而不是字母占位。
- Agent 按钮随主题改变外框和阴影；不覆盖首屏核心文案。
- 图片加载失败时显示同尺寸的图标回退，不出现破图。

## 视觉系统

| 元素 | 白昼画布 | 夜间实验室 |
| --- | --- | --- |
| 页面背景 | #F7F7F4 | #101111 |
| 主文字 | #171717 | #F4F1E8 |
| 辅助颜色 | 青绿、珊瑚、柠黄、靛蓝 | 同色系提高亮度，不使用单一蓝紫渐变 |
| 图层边框 | 半透明深灰 | 半透明暖白与彩色发光边缘 |
| 图片节点 | 白底、细边框、短阴影 | 炭黑底、细亮边、短阴影 |

字体使用现有中文系统字体，不增加负字距。圆角仅用于工具控件和图片节点，最大 8px；主题切换使用月亮/太阳图标并带 tooltip。

## 交互与状态

- 首次访问根据系统主题设置初始主题；用户手动选择后写入 `localStorage`。
- 切换主题不刷新页面，颜色和 Logo 动画在 180-240ms 内完成。
- 图片碎片仅在首屏渲染，滚动离开后停止动画，减少性能消耗。
- 资源图片加载失败时显示固定比例的空状态纹理，仍可进入工具页面。
- 未登录点击登录图标打开现有登录弹窗；已登录点击进入 `/tools`。
- 页面在 320px、768px、1440px 宽度均保持文案可读、控制按钮不重叠。

## 实现边界

- 改造范围限定为公开首页和首页 Agent 入口，不重构工具工作台。
- 移除 `AmbientField` 的光斑、粒子和渐变球效果。
- 复用现有认证和登录弹窗。
- 新增主题状态与可访问的主题切换控件。
- 能力预览优先使用本地、已构建进镜像的静态图片；不在首页请求需要登录的图库 API。

## 验收

- 首屏除核心文案与图标按钮外，无额外说明文字。
- 白昼/夜间主题均能切换、刷新后保留、系统减少动态效果时不播放动画。
- 动态 Logo 在两种主题下可见且不影响导航操作。
- 每个能力节点均可进入现有路由。
- Agent 图标在生产容器内可通过 `/agent/bingou.png` 返回 200。
- 桌面与移动截图无文字溢出、控件重叠或空白媒体区域。
