# 智能创作中心画布与 Skill 管理设计

## 1. 文档状态

- 状态：已完成产品设计，等待书面规格确认
- 目标用户：需要持续进行图片、素材、IP 和内容创作的运营及设计人员
- 设计参考：采用“即梦式创作桌面”的易用性原则，不复制具体界面或品牌元素
- 核心原则：先表达创作意图，再由 Agent 组织能力；过程可视、可编辑、可复用、可追溯

## 2. 产品目标

现有的男装生图、参考图创作、一衣多搭、封面设计、IP 衍生、模特生成和素材提取等功能已具备独立入口，但用户在复杂创作中需要反复切换页面、重复传图和重新描述需求。

新增一级产品域“智能创作中心”，将现有能力封装为可调用的 Skill。在独立的创作画布页面中，用户既可通过自然语言让 Agent 自动组织创作流程，也可手动选择 Skill 完成创作；在独立的 Skill 管理页面中，用户可维护自定义能力。

“智能创作中心”是一个新的一级导航，不替换已有功能入口。原功能页在第一阶段继续存在；画布中的系统 Skill 调用已有页面对应的领域服务，而不是复制一套生成逻辑。

## 4. 创作画布

### 4.1 页面定位

创作画布是围绕一次创作目标建立的项目桌面，而不是技术化的流程编排器。用户看到的是素材、创作动作和结果图片之间的关系，而不是端口、数据类型和复杂节点配置。

### 4.2 默认布局

```text
顶部：项目名称 | 保存状态 | 历史版本 | 导出

左侧浮动栏：常用 Skill、素材、添加文本需求、更多 Skill
中间：自由排布画布
右侧：选中项的参数、完整提示词、任务状态、输出结果
底部：Agent 对话与自由提示词输入框
```

- 画布支持无限平移、缩放、框选、多选、拖动和对齐。
- 默认不展示“工作流端口”。仅在素材被某个 Skill 使用时展示带文字的轻量连线，例如“作为主体图”“作为风格参考”。
- 结果图片可自由放置、放大和并排比较，支持在同一项目内继续使用。
- 画布每次改动自动保存，刷新、切换页面和重新登录后可恢复到最后状态。

### 4.3 卡片类型

#### 素材卡

- 本地上传图片。
- 从公共素材中心选择的图片。
- 已生成结果。
- 文本需求。
- 颜色、构图、风格等轻量参考。

素材卡显示缩略图、名称、来源和被引用次数。图片可预览大图，并可被设置为主体图、参考图、模特图或可提取素材。

#### 创作 Skill 卡

Skill 卡展示名称、当前输入素材、关键参数、提示词摘要、生成队列和结果缩略图。卡片本身保持紧凑，完整参数与完整提示词在选中后显示于右侧属性栏。

第一批系统 Skill：

- 男装视觉生成。
- 参考风格生成。
- 一衣多搭。
- 平台封面设计。
- IP 衍生工厂。
- 模特生成。
- 素材提取与入库。
- 热点查询与内容灵感。

### 4.4 Agent 与底部输入框

底部固定保留自由输入框，交互风格接近 Codex 的任务输入：用户可输入目标、约束、修改意见或临时提示词，也可附带图片和素材。

示例：

```text
用这件衬衫做三套秋季穿搭，其中一套做小红书封面，保留参考图的留白和人物远近。
```

Agent 的职责：

1. 识别用户目标与已有素材。
2. 推荐或创建必要的 Skill 卡。
3. 建议素材角色、默认参数和提示词草稿。
4. 将多步任务放入画布，但不自动覆盖用户已有的手动修改。
5. 在生成前展示执行摘要，用户可直接调整任一 Skill 卡。

Agent 不得无提示地发起高成本批量生成。涉及生成数量、付费能力或不确定素材角色时，必须由用户确认后执行。

### 4.5 结果的继续创作

生成结果的悬浮操作：

- 大图预览。
- 设为主体图。
- 设为参考图。
- 发送至另一个 Skill。
- 提取并保存为素材。
- 下载。
- 查看生成参数与完整提示词。

用户选择“继续创作”后，系统应直接在画布添加下游 Skill 卡并建立角色化连线，而不是跳转到另一个页面并丢失上下文。

### 4.6 会话、版本与历史

每个画布是一条 `CreativeCanvasSession`。会话保存画布坐标、卡片快照、素材引用、每次输入、提示词版本、任务状态、结果和操作者行为。

- 自动保存草稿。
- 支持命名版本、恢复某一版本和复制为新项目。
- 历史会话可在“历史记录”中查看，并可一键重新打开到画布。
- 画布执行时使用的 Skill 版本与提示词快照固定保存。后续修改 Skill 不得影响历史结果的可复现性。

## 5. Skill 管理

### 5.1 页面定位

Skill 管理是可视化的创作能力管理页，不向用户暴露代码、模型接口或复杂 Schema。它仅在需要新建、编辑、复制、停用和查看能力调用情况时使用，不干扰日常画布创作。

### 5.2 Skill 类型与权限

- 系统 Skill：平台维护，不能删除。用户可查看、使用，必要时复制为自定义 Skill。
- 团队 Skill：公共可见，由具备管理权限的成员创建、编辑、启用或停用。
- 自定义 Skill：创建者维护。第一版默认仅创建者可见，可选择发布为团队 Skill。

### 5.3 Skill 配置

每个 Skill 包含：

- 名称、图标、分类、简短说明和启用状态。
- 输入项：文本、单图、多图、素材库选择、单选、多选、数值和开关。
- 输入素材角色：主体图、风格参考、模特参考、姿势参考、背景参考等。
- 默认值、内置选项和必填规则。
- 提示词模板，支持 `{变量名}` 替换。
- 默认负面提示词与不可变约束。
- 输出类型：图片、文案、素材或结构化信息。
- Agent 调用说明：适用场景、前置条件、禁止使用条件及结果说明。

自定义 Skill 第一阶段只能配置和调用一个已有领域能力。它可以重用现有生图、分析或素材服务，但不支持用户自行接入外部模型接口或任意脚本。

### 5.4 增删改查

- 新建：从系统 Skill 模板或空白配置创建。
- 查看：展示完整配置、版本、样例输出和调用记录。
- 编辑：以草稿方式修改，保存后发布新版本。
- 复制：系统 Skill 和团队 Skill 都可复制为自己的 Skill。
- 删除：自定义 Skill 可删除；被画布引用时显示影响范围，历史会话保留快照而不失效。
- 启用/停用：停用 Skill 不再出现在画布常用栏和 Agent 推荐中，但历史会话仍可查看。

## 6. 关键数据模型

- `CreativeSkill`：Skill 元信息、类型、权限、状态和当前版本。
- `CreativeSkillVersion`：输入定义、提示词模板、默认参数、Agent 说明和执行器映射。
- `CreativeCanvasSession`：画布项目和会话元信息。
- `CreativeCanvasNode`：素材卡、文本卡或 Skill 卡及坐标、尺寸和内容快照。
- `CreativeCanvasConnection`：素材到 Skill 的角色化引用。
- `CreativeCanvasRun`：一次 Agent 规划或生成执行记录。
- `CreativePromptVersion`：系统草稿、Agent 草稿、用户编辑版和最终执行版。

现有的 `WorkbenchSession`、生成任务、素材资产和画廊结果继续作为领域数据来源。画布数据只保存引用和快照，不重复存储图片二进制数据。

## 7. Agent 编排规则

- 用户在底部输入框提出需求时，Agent 先生成“计划草稿”，包含建议的 Skill、所需素材和待确认参数。
- 用户可以接受整套计划、删除某个卡片或手动更换 Skill。
- Agent 创建卡片时应优先复用画布上已有素材，不能重复上传或无理由生成相同内容。
- Agent 可以建议，但不能修改用户锁定的素材角色、提示词片段或参数。
- 任一 Skill 卡均可脱离 Agent 单独运行。

## 8. 状态与异常

需覆盖：空画布、Agent 规划中、等待补充素材、待确认、生成排队、生成中、部分成功、已完成、失败、素材被删除、Skill 已停用、权限不足和保存失败。

生成中切换页面后，画布和任务状态必须恢复。生成失败时保留输入、提示词、素材和错误原因，支持在原卡片重试或复制为新卡片。

## 9. 分期范围

### 第一阶段

- 新增智能创作中心导航、创作画布和 Skill 管理页面。
- 系统 Skill 注册表，接入现有核心图片创作能力。
- 画布素材卡、Skill 卡、轻量角色连线和结果继续创作。
- 底部 Agent 输入框，支持生成流程草稿。
- Skill 的基础增删改查、版本与启用状态。
- 画布会话、提示词与 Skill 快照持久化。

### 第二阶段

- 团队 Skill 发布、权限和审核。
- Skill 模板市场、收藏和推荐。
- 多人协作、评论与画布共享。
- 更复杂的组合 Skill：将多个 Skill 发布为一个可复用流程。

## 10. 验收标准

- 用户可独立进入“创作画布”和“Skill 管理”。
- 用户可在画布上传、选择、预览并复用素材。
- 用户可通过底部自然语言输入获得 Agent 生成的可编辑流程草稿。
- 用户可不依赖 Agent，直接添加并运行任何已启用的系统或自定义 Skill。
- 每个 Skill 卡都可查看和修改完整提示词。
- 生成结果可直接作为下游 Skill 的主体或参考素材。
- 切换页面、刷新或重新登录后，画布布局、生成状态和结果均可恢复。
- 自定义 Skill 支持创建、查看、编辑、复制、启用/停用和删除。
- 已执行会话始终能查看当时的 Skill、参数和提示词版本。
- 系统 Skill 删除保护有效，停用的 Skill 不会被 Agent 新任务推荐。

## 11. 主要风险与控制

- 画布功能范围容易膨胀：第一阶段不做任意外部接口、脚本执行和组合 Skill 发布。
- Agent 误判意图：始终先提供可编辑计划草稿，生成动作需要用户确认。
- 画布过于复杂：默认展示简洁卡片和角色标签，复杂配置收进右侧栏。
- 历史不可复现：每一次执行必须保存 Skill、提示词、参数和素材引用的快照。
- 生成成本不可控：批量或多 Skill 计划需要显示数量与执行摘要。

## 12. 设计就绪结论

第一阶段实现“即梦式自由创作桌面”与“可管理的 AI 创作 Skill”两条主线：画布负责创作和编排，Skill 管理负责复用和维护，Agent 与底部自由提示词框连接两者。

在用户确认本书面规格前，不修改业务代码；确认后再编写实施计划并进入开发。
