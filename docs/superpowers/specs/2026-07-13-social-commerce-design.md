# 小红书 / 闲鱼内容设计台设计

## 背景

当前工具站已经包含 AI 生图、服装起号、零食百货、图片画廊和工具目录等能力。新增“小红书 / 闲鱼内容设计台”用于把商品、图片参考和运营目标转成可直接使用的封面方案、标题、正文文案、标签和发布检查结果。

调研结论：

- 小红书偏内容点击和种草转化，核心是封面吸引力、标题钩子、正文结构和话题标签。
- 闲鱼偏真实交易和搜索成交，核心是商品可信度、标题检索词、成色说明、瑕疵说明、配件说明和沟通话术。
- 两个平台不能共用一套模板。第一版应拆成两种平台模式，但共用同一个工作台和生成管线。

## 目标

第一版目标是提供一个可用的内容生成工作台：

- 用户选择平台：小红书或闲鱼。
- 用户输入商品/主题描述、目标人群、场景、卖点、价格/成色等信息。
- 可上传参考图，后续生成封面图片或用于提示词分析。
- 系统输出封面设计方案、图片生成提示词、标题候选、正文文案、标签/关键词和发布检查。
- 生成内容可复制到发布平台，图片结果继续复用现有图片生成和画廊能力。

## 不做范围

第一版不做：

- 自动发布到小红书或闲鱼。
- 平台账号授权、数据抓取、评论管理或私信自动回复。
- 竞品数据分析、爆款库爬取或第三方工具 API 集成。
- 精确承诺平台流量、转化率或审核通过率。
- 在 AI 生图结果里直接生成中文大字标题。中文封面标题后续应由前端模板叠加，避免图片模型产生乱码。

## 用户路径

1. 用户进入 `/tools/social-commerce`。
2. 选择平台模式：小红书或闲鱼。
3. 填写基础信息：
   - 商品/主题描述
   - 目标人群
   - 内容场景
   - 核心卖点
   - 补充要求
4. 如果是小红书，补充内容类型：
   - 种草笔记
   - 干货清单
   - 对比测评
   - 穿搭/好物图文
   - 经验分享
5. 如果是闲鱼，补充交易信息：
   - 品类/品牌/型号
   - 成色
   - 瑕疵
   - 配件
   - 价格区间
   - 转卖原因
6. 点击生成。
7. 页面展示多个结果卡片：
   - 封面方向
   - 图片提示词
   - 标题候选
   - 正文文案
   - 标签/关键词
   - 发布检查

## 平台模式

### 小红书模式

小红书模式强调“点击理由 + 内容可信 + 收藏价值”。

输出结构：

- 封面方向：大标题封面、干货卡片、产品种草、对比图、Plog 风、人物/商品主体封面。
- 标题候选：至少 6 条，覆盖痛点型、结果型、避坑型、清单型、真实体验型。
- 正文文案：开头钩子、体验/步骤、购买理由、注意事项、评论引导。
- 标签：围绕人群、场景、品类、风格和内容类型生成。
- 发布检查：检查标题党、夸大功效、过度营销、导流风险、标签缺失。

小红书标题原则：

- 优先使用“人群 + 场景/痛点 + 结果”的结构。
- 避免绝对化承诺和夸大功效。
- 标题要适合信息流快速扫读。

小红书封面原则：

- 主体清晰，第一眼能看懂内容主题。
- 标题层级少，首屏大字不超过两行。
- 适合 3:4 或 1:1 内容流展示。
- 图片提示词不生成文字，文字排版由前端模板负责。

### 闲鱼模式

闲鱼模式强调“搜索命中 + 真实可信 + 降低沟通成本”。

输出结构：

- 首图方向：真实商品首图、配件合集、细节特写、瑕疵说明图、使用场景图。
- 标题候选：至少 6 条，覆盖品牌/品类/型号/成色/核心卖点。
- 商品文案：购买时间、使用情况、成色、瑕疵、配件、转卖原因、发货说明。
- 搜索关键词：品牌词、型号词、品类词、成色词、场景词。
- 沟通话术：可小刀、验货说明、发货说明、爽快成交回复。
- 发布检查：检查成色缺失、瑕疵缺失、配件缺失、价格理由缺失和夸大描述。

闲鱼标题原则：

- 优先包含品牌、品类、型号、成色和强搜索词。
- 少用情绪化标题，避免小红书式标题。
- 不虚构品牌、型号、功能和成色。

闲鱼首图原则：

- 首图必须真实、清楚、可信，不做过度营销风。
- 二手商品优先展示实拍感、成色和配件。
- 瑕疵信息不能隐藏，应单独规划说明图。

## 数据模型

第一版不新增数据库表。所有生成结果在客户端临时展示，图片生成继续走现有 `/api/tools/image-generation` 和图片画廊保存逻辑。

核心类型建议：

- `SocialCommercePlatform = "xiaohongshu" | "xianyu"`
- `SocialCommerceInput`
- `SocialCommerceOutput`
- `CoverDesignDirection`
- `TitleCandidate`
- `PublishChecklistItem`

## 生成逻辑

`social-commerce-workflow.ts` 负责纯函数生成：

- 平台预设
- 标题候选
- 正文文案
- 标签/关键词
- 封面图片提示词
- 发布检查项

组件只负责表单状态、展示、复制和提交图片生成请求。

图片生成策略：

- 小红书默认比例：portrait。
- 闲鱼默认比例：square。
- 图片提示词明确禁止生成文字、水印、价格、平台 UI、Logo。
- 若上传参考图，提示词要求保持商品外观、颜色、规格、成色和主要细节。

## UI 设计

页面使用现有工具工作台风格：

- 左侧为输入面板。
- 右侧为结果面板。
- 平台切换使用分段控件。
- 内容类型、场景、成色等使用按钮组选项。
- 数量、图片比例等使用简洁控件。
- 结果使用独立卡片展示，提供复制按钮。

视觉上保持工具型产品的密度和清晰度，不做营销落地页。

## 错误处理

- 商品描述为空时使用平台默认示例，但提示用户补充描述效果更好。
- 闲鱼模式如果缺少成色、瑕疵、配件，发布检查中提示补充，不阻塞生成。
- 图片生成 API 失败时保留已生成的标题和文案结果，单独显示图片提交失败原因。
- 上传图片数量沿用现有工具限制，不在第一版新增复杂校验。

## 测试

新增测试文件：

- `tests/social-commerce-workflow.test.ts`

测试重点：

- 小红书模式能生成标题、正文、标签、封面提示词和检查项。
- 闲鱼模式能生成搜索型标题、商品说明、关键词、沟通话术和检查项。
- 闲鱼标题包含品牌/品类/型号/成色等输入字段。
- 小红书图片提示词禁止图片内文字。
- 闲鱼缺少瑕疵或配件信息时会产生检查提示。
- 批量候选数量稳定，空输入不会抛错。

## 验收标准

- `/tools/social-commerce` 可访问。
- 工具侧边导航出现“小红书/闲鱼”入口。
- 用户可以在小红书和闲鱼模式之间切换。
- 输入商品/主题后能生成封面方向、图片提示词、标题、文案、标签/关键词和检查结果。
- 可复制主要输出。
- 可提交图片生成请求并保存到现有图片画廊。
- 新增工作流测试通过。
- `pnpm test` 和 `pnpm lint` 至少在相关变更范围内通过。

## 风险

- 平台规则会变化，发布检查只能作为辅助，不能替代人工审核。
- AI 生成二手商品图片可能不符合真实交易要求。闲鱼模式应优先建议使用真实参考图，并避免改造成色、配件和瑕疵。
- 小红书标题如果过度追求点击，容易变成标题党。生成规则需要保守处理绝对化表达。
- 中文封面排版如果直接放进图片模型，容易出现乱码。第一版只生成无文字底图和可叠加标题文案。
