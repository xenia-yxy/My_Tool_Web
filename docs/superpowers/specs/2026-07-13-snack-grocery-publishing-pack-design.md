# 零食百货抖音发布包与素材补全设计

日期：2026-07-13

## 背景

当前系统已经有零食百货生图能力，可以根据人群、场景、品类和输出类型生成图片提示词、标题、正文、标签和选品关键词。这个能力适合生成素材，但前期抖音账号的核心目标不是直接强转化，而是稳定发布作品、跑流量、打账号标签、筛选有效粉丝，并为后期橱窗、短视频挂车和直播转化准备内容资产。

因此，本次设计把零食百货工具从“生图工具”升级为“抖音作品发布包生成器”。系统每次输出一条可发布作品，而不是只输出一张图片。

## 目标

1. 支持前期批量发布零食百货图文作品。
2. 让作品更适合跑流量、留有效粉丝和打账号标签。
3. 在素材不足时自动给出可执行替代方案，不让用户卡在“没有背景图”。
4. 支持用户自定义场景，也支持系统根据商品和品类推荐场景。
5. 为后期商品转化保留选品关键词、素材需求、风险提醒和复盘字段。

## 非目标

1. 本阶段不做自动发布到抖音。
2. 本阶段不做完整账号矩阵管理。
3. 本阶段不做第三方平台素材自动抓取。
4. 本阶段不承诺通过图文直接成交。
5. 本阶段不生成含复杂文字排版的图片，避免 AI 文字错误和低质感。

## 数据与平台依据

抖音电商达人链路包含达人带货、橱窗、短视频、直播和精选联盟等承接方式。前期内容应优先服务账号标签、粉丝筛选和后续承接，而不是每条作品都直接强销售。

参考：

- 抖音电商达人官方页：https://buyin.douyinec.com/daren
- 抖音电商学习中心：https://school.jinritemai.com/

## 用户与场景

核心用户是正在做抖音零食百货内容的运营者，前期资源有限，可能没有实拍场景素材，也不一定已经购买样品。

主要场景：

1. 只有商品图，想批量生成办公室、宿舍或出租屋场景作品。
2. 只有商品描述，想先做品类内容跑流量。
3. 没有具体商品，只想按“办公室零食”“出租屋厨房小物”等栏目批量发布。
4. 有商品图和场景图，希望生成更真实的转化素材。
5. 希望系统告诉自己还缺什么素材，以及缺素材时怎么继续做。

## 内容策略

前期内容目标是留住后期可能转化的有效粉丝，而不是吸引泛低价流量。

优先吸引的人群：

- 大学生和宿舍党。
- 办公室打工人。
- 租房党。
- 小厨房、小卫生间用户。
- 懒人家务人群。
- 返校、夏季、囤货人群。

优先内容类型：

- 清单型：适合收藏。
- 避坑型：适合停留、评论和关注。
- 场景型：适合打标签。
- 判断型：适合建立可信度。
- 评论答疑型：适合复用已有互动。

避免内容类型：

- 强喊单。
- 全网最低。
- 闭眼入。
- 未亲测却声称亲测。
- 食品功效、保健、减肥、治疗等高风险表达。

## 发布包结构

系统每次生成一个发布包，包含：

1. 作品定位：账号阶段、发布目标、内容类型、目标人群、品类、场景。
2. 标题备选：3 个抖音标题。
3. 首图方案：3 个首图钩子。
4. 组图分镜：4-6 张图的结构。
5. 每张图的生图提示词。
6. 正文文案。
7. 评论区置顶话术。
8. 抖音标签。
9. 商品或选品关键词。
10. 素材需求清单。
11. 缺素材替代方案。
12. 风险提醒。
13. 发布后复盘字段。

推荐图文结构：

```text
第1张：首图钩子
第2张：具体场景或痛点
第3张：清单或分类
第4张：避坑标准
第5张：适合谁 / 不适合谁
第6张：评论区引导或下一条预告
```

## 素材状态判断

系统根据用户输入自动判断素材状态。

### A 级：商品图 + 场景图

用途：后期转化、真实感更强的作品。

生成策略：

- 保持商品包装、颜色、规格感和数量感。
- 参考场景图的空间、光线和陈列关系。
- 生成真实场景图，减少广告棚拍感。

### B 级：商品图 + 无场景图

用途：前期测品和批量发布，优先支持。

生成策略：

- 系统根据商品和品类推荐 3-5 个场景。
- 用户可选择推荐场景，也可自定义场景。
- 生图提示词要求保持商品主体，不虚构品牌，不改变包装。

示例：

```text
商品：无糖茶饮料
推荐场景：办公室抽屉、工位桌面、公司冰箱、午休桌边、加班桌面
```

### C 级：无商品图 + 有商品描述

用途：品类内容、清单内容、避坑内容。

生成策略：

- 不生成具体品牌或具体包装。
- 输出品类场景图和内容型图文。
- 文案避免具体口味、具体功效和真实体验承诺。

### D 级：无商品图 + 无具体商品

用途：栏目化批量跑流量。

生成策略：

- 以人群、品类、场景和内容类型为核心。
- 生成通用清单、避坑、判断和评论引导内容。
- 输出后续可挂商品关键词，方便后期选品。

## 场景推荐规则

系统支持“系统推荐场景”和“自定义场景”两个入口。

推荐规则：

| 商品或品类 | 推荐场景 |
|---|---|
| 无糖饮料 | 办公桌、公司冰箱、午休桌边、办公室抽屉 |
| 坚果小包 | 办公室抽屉、会议前、加班桌面、通勤包 |
| 饼干糕点 | 下午茶桌面、工位角落、分享场景、宿舍桌面 |
| 速食夜宵 | 宿舍桌面、小锅旁边、夜晚灯光、返校囤货 |
| 收纳盒 | 凌乱桌面对比、抽屉整理、租房书桌、宿舍床边 |
| 厨房清洁 | 水槽边、灶台边、油污局部、使用前后 |
| 卫生间清洁 | 洗手台、地漏、马桶边、水垢对比 |
| 防暑降温 | 通勤包、宿舍桌面、办公室工位、返校行李 |

当用户没有上传场景图时，系统提示：

```text
你没有上传场景图，系统将自动生成推荐场景。你也可以改成自己的场景描述。
```

## 栏目模板

第一阶段只做 6 个模板，避免功能发散。

1. 宿舍零食清单。
2. 办公室抽屉零食。
3. 追剧 / 夜宵小吃。
4. 出租屋厨房小物。
5. 卫生间清洁收纳。
6. 夏季 / 返校短期好物。

每个模板支持以下发布目标：

- 跑流量。
- 留有效粉丝。
- 测品。
- 问链接。
- 后期转化预热。

## 批量发布策略

前期建议以栏目批量测试，而不是每条都重新设计。

建议节奏：

```text
单账号每天 3-5 条
三账号矩阵每天 12-15 条
连续跑 7 天
先完成 80-100 条内容测试
```

测试原则：

- 同一选题换首图。
- 同一商品换场景。
- 同一场景换标题。
- 同一标题换图文结构。
- 每次只改一个主要变量，方便复盘。

## 复盘字段

每条发布包保留以下字段：

```text
发布日期
账号
栏目
内容类型
标题
首图方案
商品或品类
素材等级
发布时间
播放量
点赞
评论
收藏
转发
主页访问
新增关注
是否有人问链接
是否有人问清单
橱窗点击
是否成交
备注
```

前期判断重点：

- 收藏率代表内容是否有用。
- 评论代表用户是否有场景和问题。
- 关注代表账号定位是否成立。
- 问链接代表后期转化信号。
- 播放高但无关注、无收藏、无评论时，可能是泛流量。

## 素材来源说明

推荐素材来源：

1. 巨量百应 / 精选联盟商品素材。
2. 商家直接提供的商品图、详情图、场景视频、授权素材包。
3. 用户自己购买少量样品后拍摄。
4. AI 基于商品参考图生成场景图。
5. 通用素材网站只用于背景氛围，不用于具体商品冒充。

高风险素材：

- 直接搬运同行抖音视频。
- 下载别人开箱视频二次剪辑发布。
- 截取买家秀当自己的素材。
- 直接使用小红书、淘宝评价图。
- 搬运直播切片。

## 合规规则

食品类内容避免：

- 减肥、治疗、降糖、降脂、养胃等功效表达。
- 未购买未体验却说“我亲测”“我吃过”。
- 绝对化承诺，比如“保证好吃”“全网最低”。
- 临期、保健食品、酒类、特殊膳食等高风险方向。

百货类内容避免：

- 夸大承重、除菌、除甲醛等难验证功效。
- 虚构使用前后效果。
- 未实测却宣称长期使用体验。

## 系统改造建议

在现有零食百货工具上新增“发布包模式”。

新增输入：

- 账号阶段。
- 发布目标。
- 内容类型。
- 素材状态。
- 商品图上传。
- 场景图上传。
- 商品描述。
- 自定义场景。
- 是否使用系统推荐场景。
- 栏目模板。

新增输出：

- 发布包预览。
- 分镜提示词。
- 素材需求清单。
- 缺素材替代方案。
- 复盘字段模板。

保留现有能力：

- 批量数量。
- 商品参考图上传。
- 生成图片。
- 保存图库。
- 标题、正文、标签和关键词生成。

## 验收标准

1. 用户没有上传场景图时，系统能推荐场景并继续生成发布包。
2. 用户没有上传商品图时，系统能切换到品类内容，不虚构具体商品。
3. 发布包包含标题、首图、分镜、提示词、正文、评论引导、标签、关键词、素材需求、风险提醒和复盘字段。
4. 系统至少支持 6 个栏目模板。
5. 生成结果明确区分“跑流量内容”和“转化内容”。
6. 风险提醒能覆盖食品和百货的基础违规风险。
7. 现有批量生图和图库能力不被破坏。

## 推荐实施顺序

1. 先实现发布包数据结构和生成函数。
2. 再实现素材状态判断和场景推荐。
3. 然后改造零食百货工具 UI，增加发布包模式。
4. 最后接入批量生成和图库保存。
