# 男装穿搭生图说明

## 单品穿搭生图

入口：`/tools/menswear/single-outfit`

1. 上传一件或多件需要保留的服装、裤子、内搭、鞋包或配饰。
2. 可上传构图参考图，并分别选择构图、背景和动作是否保持参考图，或自行改写。
3. 脸部参考图支持本地上传和素材库的 `model_face` 分类；可选择露脸、无头、不戴口罩或戴口罩。
4. 可控制人物远近、人物占比、图片比例和生成数量。每张结果只输出一套穿搭。

## 一衣多搭与平铺拆分

入口：`/tools/menswear/multi-outfit`

1. 上传锁定主商品，并可上传一张平铺多搭参考图。
2. 点击“AI 识别平铺套数”后，系统回填识别套数，用户仍可手动修正。
3. 选择“按套数拆分为单张人物图”时，必须上传平铺多搭参考图；第 N 张输出固定对应平铺图从左到右、从上到下的第 N 套组合。
4. 平铺参考的构图、背景、动作均可单独保持或自定义；支持脸部参考、无头/露脸和口罩设置。

## 历史与画廊

所有结果保存在统一图片画廊和对应功能历史中。画廊详情会保存并显示参考图用途，例如锁定主体商品图、平铺多搭参考图和脸部身份参考图。

## 部署依赖

本次版本增加 `AiImageAsset.referenceLabels` 数据库字段。部署时必须应用 Prisma 迁移 `20260717040000_add_ai_image_reference_labels`，否则新生成结果无法保存参考图角色标签。
