# 2026-07-15 男装素材、风格参考生图与画廊修复交付说明

## 本次完成

1. 素材库支持上传整图后框选区域，裁剪成素材并保存到公开素材库。
2. 男装新增「风格参考生图」入口：上传多张服装主图，再上传 1 张风格参考图，保留主图真实商品细节，只参考风格图的光线、镜头、背景氛围和色彩。
3. 男装工作台新增入口：`/tools/menswear/style-reference`。
4. 导航正式命名：
   - 男装起号 -> 男装视觉工作台
   - 女装起号 -> 女装视觉工作台
5. 图片画廊详情页的参考图下方显示角色说明：
   - 男装风格参考生图：主图 1、主图 2、风格参考图
   - IP 衍生工厂：主 IP 图、辅助参考图
   - IP 原型：草稿/主体参考图、风格参考图
   - 男装严格保真：男装控制参考图
6. 修复 AI 生图提示词弹窗复用旧会话提示词的问题。现在每次打开弹窗都会基于当前页面表单重新生成提示词，保存后提交用户修改后的完整提示词。
7. 修复男装风格参考生图提交时报“工具类型不正确”的问题：已注册 `menswear-style-reference` 工作记录工具，并补齐图片生成 sourceTool 到历史记录的映射。
8. 新增「男装一衣多搭生图」：
   - 入口：`/tools/menswear/multi-outfit`
   - 支持上传 1-6 张服装主体参考图。
   - 支持「上身模特」和「无模特平铺」两种展示方式。
   - 支持标题/搭配名版式或无文字版式。
   - 默认横版合集，适合生成 3-6 套一衣多搭展示图。

## 关键交互

- 素材库上传图片后先进入裁剪弹窗，用户框选需要保存的区域，再点击「保存选区」，之后点击「保存到公开素材库」。
- 男装风格参考生图要求：
  - 服装主图：1-6 张。
  - 风格参考图：1 张。
  - 可选择或自定义「保留内容」和「参考风格」。
  - 提交前可在完整提示词弹窗中修改最终提示词。
- 男装一衣多搭生图要求：
  - 主体参考图：1-6 张。
  - 主商品必须出现在每一套搭配里。
  - 上身模特模式用于生成类似模特穿搭合集。
  - 无模特平铺模式用于生成类似商品平铺搭配合集。
