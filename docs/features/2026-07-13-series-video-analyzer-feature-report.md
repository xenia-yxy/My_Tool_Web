# 功能报告：系列视频分析工具

## 1. 功能概述

系列视频分析工具用于复盘“挑战 100 个自媒体赛道”这类系列化短视频。用户可以输入视频链接、赛道、标题、内容简述和关键数据，系统会自动识别平台、计算核心指标、诊断内容问题，并给出下一条视频的执行建议。

当前版本定位为本地规则分析工具，不抓取第三方平台数据，不依赖 AI 接口，不做历史数据落库。它的核心价值是把短视频复盘从口头判断变成结构化判断。

## 2. 功能入口

- 导航分组：创作

## 3. 使用流程

1. 打开“系列视频分析”工具页。
2. 填写视频链接、平台、赛道、系列期数、标题、账号类型和内容简述。
3. 填写播放、点赞、评论、收藏、转发、涨粉、完播率、平均观看等数据。
4. 查看系统生成的分析结果、分析依据、数据解读、下一步建议和标题候选。
5. 点击“复制报告”，将本次复盘报告复制到剪贴板，用于继续和 Codex 沟通或归档。

## 4. 参数说明

### 视频链接

用途：记录素材来源，并自动识别平台。

支持识别：

- 抖音：`douyin.com`、`v.douyin.com`
- 小红书：`xiaohongshu.com`、`xhslink.com`
- B站：`bilibili.com`、`b23.tv`
- 其他链接：识别为其他平台

说明：当前版本不会抓取平台数据，链接只用于平台识别和复盘归档。

### 平台

用途：确定报告中的平台标签。

选项：

- 自动识别
- 抖音
- 小红书
- B站
- 其他平台

说明：自动识别不准时可以手动选择，手动选择优先于链接识别。

### 赛道

用途：定义本次挑战对象，并影响标题候选和下一条建议。

示例：

- 舞蹈博主
- AI 工具号
- 本地生活探店
- 情感号
- 好物测评号

### 系列期数

用途：记录当前视频是系列中的第几期，便于长期复盘。

示例：

- 第 1 期：挑战开始
- 第 2 期：过程踩坑
- 第 3 期：最终复盘

### 发布时间

用途：用于人工复盘发布时段和数据表现。

说明：当前版本不直接参与规则诊断。

### 视频时长

用途：配合平均观看时长，辅助判断观众大概在哪个阶段流失。

单位：秒。

### 标题

用途：进入复制报告，并辅助判断点击理由是否明确。

建议标题应包含：

- 挑战对象
- 时间成本
- 结果
- 翻车点
- 普通人视角

示例：`挑战舞蹈博主第 1 天，我发现普通人最难的是面对镜头`

### 账号类型

用途：辅助判断人设承接。

示例：

- 自媒体赛道实验员
- 普通人实测
- 养成系
- 真实复盘

### 内容简述

用途：补充视频内容语境，帮助区分问题发生在选题、结构、表达还是人设。

建议写清楚：

- 这条视频讲了什么
- 最大冲突是什么
- 过程里发生了什么
- 最终数据或结论是什么
- 你自己的判断是什么

## 5. 数据指标说明

### 播放量

含义：后台显示的播放数量。

用于判断：

- 选题是否获得基础分发
- 标题封面是否有点击理由
- 开头是否足够吸引平台继续推荐

### 点赞

含义：观众对内容的轻量认可。

用于判断：

- 观点是否被认同
- 情绪是否有共鸣
- 视频表达是否顺畅

### 评论

含义：观众愿意参与讨论的强度。

用于判断：

- 选题是否有争议
- 评论区是否能承接下一期选题
- 观众是否愿意反馈自己的赛道或数据

### 收藏

含义：观众认为内容有复看价值。

用于判断：

- 内容是否有方法论
- 是否有避坑价值
- 是否适合做清单、教程、复盘类内容

### 转发

含义：观众愿意把视频推荐给别人。

用于判断：

- 选题是否具备传播性
- 内容是否适合同类人群讨论

### 涨粉

含义：这条视频带来的新增粉丝。

用于判断：

- 观众是否记住账号
- 系列主线是否清晰
- 人设是否有继续关注价值

### 完播率

含义：完整看完视频的用户比例。

单位：百分比，输入 0-100。

用于判断：

- 前 3 秒是否有效
- 中段结构是否拖沓
- 视频长度是否合理

### 平均观看

含义：后台显示的平均观看秒数。

用于判断：

- 观众大概在哪个阶段流失
- 是否需要缩短铺垫
- 是否需要提前给结果或冲突

## 6. 计算指标

### 互动率

公式：

```text
互动率 = (点赞 + 评论 + 收藏 + 转发) / 播放量
```

用途：判断观众是否只是路过，还是产生了有效互动。

### 点赞率

公式：

```text
点赞率 = 点赞 / 播放量
```

用途：判断内容观点或情绪是否被轻量认可。

### 评论率

公式：

```text
评论率 = 评论 / 播放量
```

用途：判断选题是否有讨论空间。

### 收藏率

公式：

```text
收藏率 = 收藏 / 播放量
```

用途：判断内容是否有复看、方法、避坑或参考价值。

### 转发率

公式：

```text
转发率 = 转发 / 播放量
```

用途：判断内容是否有传播价值。

### 涨粉率

公式：

```text
涨粉率 = 新增粉丝 / 播放量
```

用途：判断人设和系列主线是否有关注价值。

## 7. 诊断规则

### 只有链接，没有数据

诊断：需要补充基础数据。

建议：

- 补充播放、点赞、评论、收藏、涨粉和完播率。
- 补充标题和内容简述。
- 先围绕“真实过程 + 数据结果”做复盘。

### 播放高，涨粉低

触发逻辑：

```text
播放量 >= 5000 且涨粉率 < 0.1%
```

诊断：播放已经打开，但人设或系列承接弱。

建议：

- 开头明确你是谁、正在挑战什么。
- 补一条人设复盘内容。
- 结尾固定引导观众评论下一个想看的赛道。

### 播放低，收藏高

触发逻辑：

```text
播放量 <= 500 且收藏率 >= 6%
```

诊断：内容有价值，但标题封面或前 3 秒弱。

建议：

- 重写标题，把结果、成本、天数或翻车点前置。
- 封面使用“赛道 + 普通人真能做吗”的结构。
- 前 3 秒直接给结论或冲突。

### 评论高，收藏低

触发逻辑：

```text
评论率 >= 2% 且收藏率 < 1%
```

诊断：情绪或争议够了，但信息沉淀不足。

建议：

- 从评论区挑具体问题做回应。
- 在情绪点后补步骤、数据或成本。
- 置顶评论询问是否要按网友建议重测。

### 收藏高，评论低

触发逻辑：

```text
收藏率 >= 4% 且评论率 < 0.5%
```

诊断：内容有用，但互动设计不足。

建议：

- 结尾加具体问题。
- 将有用信息拆成 3 个判断。
- 标题加入“新手先看完再做”。

### 完播率偏低

触发逻辑：

```text
0 < 完播率 < 35%
```

诊断：开头钩子或中段节奏有问题。

建议：

- 删除长铺垫。
- 开头 3 秒抛出最大翻车点。
- 中段按“规则-执行-数据-结论”组织。

### 涨粉率较高

触发逻辑：

```text
涨粉率 >= 0.8%
```

诊断：当前赛道和表达方式值得继续。

建议：

- 继续做同赛道第 2 条。
- 用评论区问题作为下一条开头。
- 同赛道至少记录 3 条数据再判断。

## 8. 输出内容

### 分析结果

展示：

- 平台标签
- 当前评级
- 核心诊断
- 复制报告按钮

评级包括：

- 待补充数据
- 建议继续
- 建议优化后重测
- 建议换切口
- 需要继续观察

### 分析依据

展示每个关键指标的公式、用途和当前值。

包括：

- 互动率
- 涨粉率
- 收藏率
- 完播率

### 数据解读

根据输入数据输出解释，例如：

- 互动率说明观众是否只是路过。
- 涨粉率说明人设是否被记住。
- 收藏率高说明内容有参考价值。
- 评论率高说明选题有讨论空间。

### 下一步建议

根据核心诊断输出可执行动作，例如：

- 重写标题封面。
- 调整前 3 秒。
- 承接评论区。
- 继续同赛道第二条。
- 暂停该赛道或换切口。

### 标题候选

默认生成 3 类标题：

- 结果型：`我用 7 天挑战 XX，普通人到底能不能做起来`
- 过程型：`挑战 XX 第 1 天，我发现新手最容易卡在这一步`
- 反差型：`我以为 XX 很好做，结果真实数据出来了`

## 10. 异常和边界情况

### 空数据

行为：不报错，输出待补充数据。

### 负数

行为：逻辑层按 0 处理。

### 完播率超过 100

行为：逻辑层按 100 处理。

### 播放量为 0 但存在互动

行为：输出异常数据提示，建议核对后台数据。

### 无法识别链接

行为：识别为其他平台，仍可继续分析。

### 未填写赛道

行为：使用“当前赛道”作为占位，不阻断标题候选和建议生成。

## 15. 当前结论

系列视频分析工具第一版已经具备可用价值。它适合作为“挑战不同自媒体赛道”系列的固定复盘工具，能够帮助用户把每条视频的数据转化为内容判断，并快速生成下一条视频的优化方向。

当前版本最适合用于单条视频复盘。下一阶段应优先做历史记录和多条视频趋势分析，让工具从“单条诊断”升级为“赛道实验管理”。
