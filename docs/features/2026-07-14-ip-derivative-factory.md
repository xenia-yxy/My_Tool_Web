# 功能开发文档：IP 衍生工厂

## 1. 背景和目标

用户已经可以生成 IP 原型，但缺少基于同一个 IP 继续生成表情包、动作、换装、场景海报等衍生资产的工作台。本功能目标是把“单次 IP 生图”扩展成“可持续运营的 IP 资产变体生产”。

## 2. 已确认需求

- 新增独立工具页：IP 衍生工厂。
- 支持上传主 IP 图，作为必须保持一致的角色身份。
- 支持上传参考图，用于动作、服装、装饰或场景参考。
- 支持四个首版模式：表情包、动作姿势、换装装饰、场景海报。
- 支持完整提示词预览和可编辑。
- 生成结果进入现有图片画廊和工具历史记录。
- 历史记录、页面切换状态恢复沿用现有 workbench session 能力。

## 3. 本次不做

- 不做 GIF/视频动作生成。
- 不做四格剧情的多图连续叙事生成，仅保留后续扩展方向。
- 不做独立 IP 资产库数据表，首版通过图片画廊和历史记录承接。
- 不做局部遮罩编辑和骨骼姿态控制。

## 4. 用户流程

1. 用户进入 `/tools/ip-factory`。
2. 上传主 IP 图。
3. 选择创作模式：表情包、动作姿势、换装装饰、场景海报。
4. 选择预设或填写自定义要求。
5. 可选上传参考图。
6. 查看完整提示词并生成。
7. 结果进入图片画廊，同时当前工作状态写入历史。

## 5. 前端范围

- 新增 `IpDerivativeFactoryWorkbench` 客户端组件。
- 新增 `/tools/ip-factory` 页面。
- 导航创作栏新增 `IP 衍生工厂`。
- 工作台包含主 IP 图上传、参考图上传、模式切换、预设选择、保留规则、输出用途、批量数量、生成按钮和结果提示。

## 6. UI/UX 要求

- 页面应像工具工作台，不做营销落地页。
- 主 IP 图和参考图必须在界面上明确区分。
- 文案强调“保持 IP 身份一致”，避免用户误以为参考图会替换主形象。
- 表情包模式需要支持“无文字版”和“带文字版”。
- 结果统一提示去图片画廊管理。

## 7. 后端范围

- 首版复用 `/api/tools/image-generation`。
- `sourceTool` 新增 `ip-factory`，用于历史记录归类。
- 生图模式使用现有 `custom` 模式，参考图走 multipart edit。

## 8. 数据和存储

- 不新增数据库表。
- 结果仍写入 `AiImageAsset`、`AiImageJob`。
- 工作状态仍写入 `WorkbenchSession`。
- 参考图保存逻辑复用现有图片生成 API。

## 9. 业务规则

- 主 IP 图是身份参考，必须保留角色轮廓、脸、颜色、标志元素、画风。
- 参考图只用于动作、衣服、装饰或场景，不允许替换主 IP。
- 表情包带文字版允许输出短字，但无文字版必须明确禁止文字。
- 所有模式默认禁止水印、品牌 logo、错误文字和无关文字。

## 10. 异常和边界情况

- 未上传主 IP 图时不能提交。
- 表情包带文字版但没有填写文案时使用预设文案。
- 参考图为空时按文字生成变体。
- 图片生成失败时显示错误并保留当前输入。

## 11. 验收标准

### 功能验收
- [ ] 可以进入 IP 衍生工厂页面。
- [ ] 可以上传主 IP 图和参考图。
- [ ] 四个模式都能生成完整提示词。
- [ ] 可以提交生成并进入统一图片画廊。
- [ ] 历史记录归类到 IP 衍生工厂。

### 前端验收
- [ ] 导航在创作栏显示 IP 衍生工厂。
- [ ] 页面切换后提示词和状态可恢复。
- [ ] 按钮禁用状态合理。

### 后端验收
- [ ] `sourceTool=ip-factory` 映射到 `ip-factory` 历史工具。
- [ ] 图片资产可保存到现有画廊。

### UI/UX 验收
- [ ] 主 IP 图和参考图不会混淆。
- [ ] 表情包、动作、换装、场景模式文案清晰。

### 异常情况验收
- [ ] 未上传主 IP 图时阻止生成。
- [ ] API 失败时显示错误。

## 12. 测试建议

- `tests/ip-derivative-factory.test.ts`：测试预设和提示词构建。
- `tests/image-generation-workflow.test.ts`：测试历史映射。
- `tests/tool-navigation.test.ts`：测试导航位置。
- `tests/workbench-tool-registry.test.ts`：测试注册表覆盖。

## 13. 开发边界

本次只做首版 MVP，不新增独立后端模型，不改图片提供商接入方式，不做视频/GIF。

## 14. PR 和上线影响

- 有新增页面和导航入口。
- 无新增环境变量。
- 无新增数据库迁移。
- 复用现有图片生成能力，生产上线前需确认图片模型凭证可用。
