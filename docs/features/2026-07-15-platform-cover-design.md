# 2026-07-15 平台封面设计交付说明

## 本次完成

1. 新增「平台封面设计」独立工具入口：`/tools/platform-cover-design`。
2. 导航位置：创作 -> 平台封面设计。
3. 支持上传 1 张封面原图，作为主体和构图基础。
4. 支持上传 0-6 张风格参考图，只参考版式、色彩、装饰元素和视觉层级。
5. 支持平台：
   - 小红书
   - 抖音图文
   - 视频号
   - 公众号
   - 闲鱼
6. 支持封面目标：
   - 种草封面
   - 知识干货
   - 对比避坑
   - 清单合集
   - 商品首图
   - 个人 IP 封面
   - 自定义
7. 支持文字模式：
   - 无文字底图：禁止图片内生成文字，只把标题作为构图参考。
   - 尝试带字：允许模型尝试生成标题/副标题，但提示词限制只能使用用户给定文案。
8. 结果进入统一图片画廊；详情页参考图会显示「封面原图」和「风格参考图」角色。

## 提示词约束

- 第 1 张图片固定为封面原图。
- 必须保留封面原图的主体、商品、人物、脸部、关键构图和真实质感。
- 风格参考图不得覆盖原图主体，不复制参考图中的人物、商品、品牌或具体文案。
- 无文字模式会强制禁止图片中文字、标题、价格、标签、logo、水印、按钮、账号或说明。
