# Ne/Ti/Ni/Te 过程文档

记录日期：2026-05-25

## 文档定位

这份文档用于保存本项目从原始 idea 到第一阶段 MVP 方向的关键判断。

它不是逐字聊天记录，而是后续 PRD、UI 设计、开发文档和验收的上游依据。

## 0. 原始 idea 与上下文

原始 idea：

```text
搭建个人网站，与 IP 自媒体结合。
核心用途：个人名片 + 个人知识库 + 自研工具/产品展示 + SOP 企业服务。
后期可接入公司业务，并通过抖音、小红书引流，增强可信度，最终实现知识付费、SOP 搭建等变现。
```

初始边界：

- 核心用户：本人 + 对 AI 实践感兴趣的陌生访客 + 潜在企业客户。
- 内容形态：前期图文，记录真实 AI 实践经验。
- 技术约束：一个人开发，时间有限，AI 辅助，先 Web 端。
- 商业目标：长期通过工具付费、知识付费、企业服务变现。

## 1. 第一轮产品思考摘要

### 1.1 Ne-A 自由探索

关键直觉：

- 网站是数字据点，不是静态展示页。
- 网站要承载个人名片、知识库、自研工具、项目展示和 SOP 服务入口。
- 公私分离是长期核心：登录前是公开名片和内容，登录后是私人工作台。
- 内容来自真实工作经验捕获，不是为了运营而硬造内容。
- 工具聚焦创作、效率、学习、SOP，不做泛娱乐或生活工具。
- 公众号、抖音、小红书是入口，不是核心载体。

### 1.2 Ne-B 结构化整理

核心模块：

1. 个人名片：让访客知道这个人是谁、在做什么、有什么能力。
2. 个人知识库：公开文章 + 私密笔记，公私分离。
3. 自研工具合集：前期自用，后期公开或付费。
4. App / 产品介绍：展示做过或正在做的产品。
5. SOP 企业服务入口：面向 B 端的付费服务。

核心用户：

- 本人：第一用户，日常记录、使用工具、管理知识。
- 陌生访客：通过内容平台进入，判断是否值得关注。
- 潜在企业客户：判断是否可以合作 SOP / 自动化服务。

关键风险：

- 时间精力有限。
- 内容冷启动。
- B 端转化周期较长。
- 如果首屏不高级，信任建立会变弱。

### 1.3 Ti 提纯

真实需求：

- 公私分离的内容管理。
- 高级可信的公开首页。
- 工具、知识、项目和服务入口。
- 后续管理端用于上架、发布、隐藏和监控。

暂缓需求：

- 多用户系统。
- 工具状态完整后台。
- 移动端极致体验。
- 小程序。
- 完整付费系统。

核心对象：

- User
- Note
- Tool
- Project
- Service
- HomeSection
- Contact / Conversion

关键矛盾：

```text
首页既要高级好看，又要能承载多个入口。
必须克制设计，不能把首屏做成普通简历，也不能做成纯特效 demo。
```

### 1.4 Ni 收束

产品主轴：

```text
公私分离的 AI 实践者个人网站。
对外是高级数字名片、知识库、工具和服务入口。
对内是私人工作台、知识沉淀和工具宿主平台。
```

核心闭环：

- 内容闭环：工作经验 -> 私人笔记 -> 挑选发布 -> 公开文章 -> 吸引访客。
- 信任闭环：访客阅读/浏览 -> 认可能力 -> 了解工具/项目/服务 -> 联系或付费。
- 个人闭环：本人持续使用 -> 内容和工具持续积累 -> 网站越来越可信。

## 2. 第一阶段重新 Ne-A：公开首页优先

触发原因：

最初曾考虑先做登录后台，但重新讨论后确认：第一阶段最重要的是网站门面，也就是访客看到的公开首页。

新的关键直觉：

- 首页是网站的脸面，先让访客建立信任。
- 第一印象要是：这个人很懂 AI，也真的在一线做东西。
- 不要黑色主视觉。
- 视觉要浅色、高级、干净、有动态。
- 网站不是展示个人信息，而是展示一个人的系统能力。
- 入口要清楚：知识库、工具、项目、SOP 服务、联系。
- 国内参考模式更有趣：个人品牌站 + 工具导航 + 知识资产 + 自媒体转化。

## 3. 国内参考候选池

参考类型：

| 类型 | 可借鉴能力 |
| --- | --- |
| 独立开发者个人站 | 用个人站承载作品、文章、工具、项目经历，不只是简历 |
| AI 工具箱 / 工具导航 | 工具入口、工具卡片、分类、未来付费下载/使用 |
| 个人 AI 独立站 / 知识资产化 | 把知识库、智能体、工具、会员制包装为个人品牌资产 |
| 自媒体工作台 | 自媒体工具、素材库、内容创作入口 |
| 独立开发资源导航 | 创作者资源聚合、付费内容入口、小报童/竹白等转化路径 |

可吸收功能：

- 高级首屏。
- 一句话强定位。
- 入口矩阵。
- 工具状态标签。
- 精选知识/工具/项目。
- 联系和咨询入口。
- 后续管理端用于内容、工具、项目、服务和监控。

## 4. 第一阶段 Ne-B 结构化整理

可能用户：

- 从抖音/小红书来的陌生访客。
- 对 AI 实践、自动化、工具感兴趣的人。
- 潜在企业客户。
- 未来可能购买知识、工具或服务的人。

使用场景：

- 访客第一次进入网站，判断你是否可信。
- 访客想看看你有什么工具、知识、项目。
- 企业客户想判断你能不能做 SOP / 自动化服务。
- 你后续通过管理端上架知识、工具、项目和服务入口。

核心机会：

- 首页成为高级数字名片。
- 用网站本身的质感证明你不是普通博主。
- 用入口矩阵展示这个网站未来会长出工具、知识、产品和服务。
- 给后续转化留好位置。

## 5. 第一阶段 Ti 提纯

真实需求：

1. 首页必须先建立信任。
2. 首页必须高级，但不能黑色。
3. 首页必须有明确入口。
4. 首页必须能承接转化。
5. 后台未来必要，但第一阶段不抢戏。

暂缓需求：

- 完整后台。
- 完整付费系统。
- 复杂 3D / 重 WebGL。
- 完整知识库和工具运行。
- 多用户和评论互动。

关键约束：

- 不能像简历。
- 不能像普通博客。
- 不能用黑色作为主视觉。
- 不能为了酷而牺牲清楚。
- 动效要高级、轻盈、克制。

## 6. 第一阶段 Ni 收束

阶段主轴：

```text
先做一个浅色、高级、带动态交互的 AI 实践者公开首页。
让访客第一眼觉得：这个人很懂 AI，也真的在一线做东西。
同时让访客能进入知识库、工具、项目和 SOP 服务四个方向。
```

## 7. 第一阶段 Te 落地摘要

阶段名称：

```text
阶段 1：高级公开首页 MVP
```

MVP 必做：

- 浅色高级首屏 Hero。
- 强定位文案。
- 高级动态效果：浅色动态网格、光晕跟随、轻量粒子、入口卡片 hover / 磁吸微交互。
- 入口矩阵：知识库、自研工具、项目展示、SOP 服务、联系/咨询。
- 精选展示：精选知识 2 条、精选工具 2 个、精选项目 1 个。
- 转化入口：联系我、获取工具、咨询 SOP 服务。

MVP 最小底座：

- 首页内容先使用静态数据。
- 保留未来管理端可管理的字段结构。
- 公开路由预留：`/knowledge`、`/tools`、`/projects`、`/services`。
- 动效组件独立封装。

暂不做：

- 完整后台。
- 真实支付。
- 多用户。
- 完整知识库详情。
- 完整工具运行。
- 复杂 3D / 重 WebGL。
