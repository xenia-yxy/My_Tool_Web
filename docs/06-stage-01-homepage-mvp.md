# 阶段 1：高级公开首页 MVP

记录日期：2026-05-25

## 1. 阶段目标

第一阶段先完成公开首页，而不是后台。

目标是让陌生访客第一眼产生判断：

```text
这个人很懂 AI，也真的在一线做东西。
```

这个首页是网站的脸面，也是后续知识库、工具、项目、SOP 服务和转化入口的承接页。

## 2. 用户角色

| 用户 | 进入页面的原因 | 想得到的结果 |
| --- | --- | --- |
| 陌生访客 | 从抖音、小红书、公众号等入口进入 | 快速判断这个人是否可信 |
| AI 实践关注者 | 想看知识、工具和项目 | 找到知识库和工具入口 |
| 潜在企业客户 | 判断是否能做 SOP / 自动化服务 | 找到服务说明和联系入口 |
| 本人 | 检查公开门面 | 看到网站是否能承接个人 IP |

## 3. 第一阶段范围

### P0 必做

- 浅色高级首屏 Hero。
- 一句话强定位。
- 高级但克制的动态效果。
- 入口矩阵：
  - 知识库
  - 自研工具
  - 项目展示
  - SOP 服务
  - 联系 / 咨询
- 清晰的行动入口。

### P1 可做

- 精选知识 2 条。
- 精选工具 2 个。
- 精选项目 1 个。
- 社交入口。
- 入口卡片 hover / 磁吸微交互。
- 轻量滚动显现。

### P2 后置

- 付费标记占位。
- 管理端入口。
- 访问监控能力。
- 转化监控能力。

## 4. 不做范围

- 不做完整后台。
- 不做登录 UI。
- 不做真实支付。
- 不做多用户。
- 不做评论、点赞、收藏。
- 不做完整工具运行逻辑。
- 不做完整知识库详情。
- 不做复杂 3D / 重 WebGL。

## 5. 页面结构

```text
首页 /
  1. 顶部导航
  2. 首屏 Hero
  3. 入口矩阵
  4. 精选知识
  5. 精选工具
  6. 精选项目
  7. SOP 服务与联系
```

## 6. 视觉方向

```text
浅色
高级
干净
科技感
产品感
动态但克制
不使用黑色主视觉
```

适合的动态：

- 浅色动态网格。
- 光晕跟随。
- 轻量粒子。
- 磁吸入口卡片。
- 滚动显现。

不适合的动态：

- 满屏烟花式粒子。
- 黑色赛博风。
- 复杂 3D 模型。
- 影响移动端性能的重 WebGL。

## 7. 内容结构草案

### 首屏定位

需要表达：

```text
AI 实践者
一线做东西
数字系统构建
工具、知识、项目和 SOP 服务都在这里生长
```

### 入口矩阵

| 入口 | 当前阶段 | 后续方向 |
| --- | --- | --- |
| 知识库 | 占位 + 精选内容 | 公开文章、分类、搜索、付费知识 |
| 自研工具 | 占位 + 工具卡片 | 私用、内测、公开、付费 |
| 项目展示 | 展示 1 个项目 | 产品介绍页、案例页 |
| SOP 服务 | 展示服务方向 | 咨询、案例、服务流程 |
| 联系 | 联系入口 | 微信、邮箱、表单、社交平台 |

## 8. 验收标准

- 访客 3 秒内知道这个网站是 AI 实践者的个人数字据点。
- 第一屏看起来高级，不像普通博客或简历模板。
- 页面不使用黑色主视觉。
- 入口矩阵清楚，能看到知识库、工具、项目、SOP 服务。
- 动效存在，但不喧宾夺主。
- 移动端基础不崩。
- 没有引入完整后台、支付、多用户等超范围内容。
