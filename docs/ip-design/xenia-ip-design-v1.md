# Xenia IP 设计方案 V1

记录日期：2026-07-13

## 1. 设计目标

为当前个人网站与 IP 自媒体产品建立一套可持续复用的品牌 IP。这个 IP 不只是装饰形象，而是贯穿公开首页、工具台、知识库、IP 原型工坊、SOP 服务页和社媒内容的识别资产。

当前系统已经具备 IP 原型工坊、AI 生图、图片画廊、知识库发布和工具台工作流。V1 设计目标是先把 IP 的立意、视觉锚点、参考图结构和场景图方向确定下来，再进入真实生图和前端落地。

## 2. IP 立意定义

### 2.1 核心定位

名称：Xenia 数字工作流分身

一句话定义：把混乱想法整理成可发布资产的 AI 实践者分身。

身份：AI 实践者、内容生产者和工作流整理者的数字化表达。

角色：帮助用户完成从计划、创作、生成到发布的闭环。

适用系统：个人网站、公开知识库、工具台、IP 原型工坊、AI 生图工具、SOP 服务页、短视频和图文账号视觉。

### 2.2 目标用户

- 第一用户：站点所有者本人，用于统一内容生产、工具使用和服务表达。
- 第二用户：从抖音、小红书、搜索或朋友推荐进入的陌生访客。
- 第三用户：潜在企业客户，用于理解 AI 工具、SOP 服务和真实实践能力。

### 2.3 性格关键词

- 清晰：能把复杂问题拆成步骤。
- 可信：不像营销号，不靠夸张科技感建立印象。
- 直接：给出明确下一步，不绕弯。
- 耐心：适合引导用户完成工具流程。
- 有手作感：强调真实实践，不是空泛 AI 概念。

### 2.4 视觉关键词

- 浅色高级感
- 干净线条
- 工作流节点
- 笔记和便签
- 小屏幕 / 控制台
- 轻量玻璃质感
- 纸张和知识卡片
- 自然光

### 2.5 禁止方向

- 不做幼态卖萌吉祥物。
- 不做暗黑赛博人形机器人。
- 不做复杂机甲。
- 不做强营销海报风。
- 不做满屏霓虹和重紫蓝渐变。
- 不把 IP 设计成与本人专业可信度冲突的娱乐角色。

## 3. 推荐形象方向

V1 推荐使用“人物型内容 IP + 工作流助手属性”。

理由：

1. 当前公开首页要让访客 3 秒内看懂“这个人是谁、做什么”，人物型 IP 比纯抽象标志更能承接个人品牌。
2. 当前工具台已经建立“规划 -> 创作 -> 生成 -> 发布”流程，IP 需要能自然出现在工具引导和场景图里。
3. 潜在企业客户关注可信、清晰、可执行，过度卡通或科幻会削弱专业感。

## 4. 第一参考图设计：简笔画 + 风格出 IP

第一阶段不直接追求精美，而是用简笔画固定轮廓、姿态、道具和气质。参考图分四类。

| 参考类型 | 作用 | 说明 |
| --- | --- | --- |
| 简笔草图 | 固定轮廓、比例、姿态 | 用线条表达人物、节点、便签、小屏幕 |
| 风格参考 | 固定色彩、质感、镜头语言 | 浅底、软阴影、轻玻璃、自然光 |
| 品牌参考 | 固定与网站 UI 的关系 | 贴近首页和工具台，不做孤立角色 |
| 反向参考 | 固定不要什么 | 排除暗黑、幼态、机甲、重霓虹 |

### 4.1 三个简笔方向

方向 A：数字主理人

- 轮廓：人形为主，比例接近真实但轻度简化。
- 道具：手持小屏幕或笔记本。
- 气质：专业、冷静、可出现在首页。
- 适用：公开首页、文章作者形象、社媒头像。

方向 B：工作流助手

- 轮廓：半人形或轻量机器人，但不要机甲。
- 道具：节点、流程线、任务卡。
- 气质：工具感、陪伴感。
- 适用：工具台、计划中心、AI 生图引导。

方向 C：知识工匠

- 轮廓：人形 + 便签/卡片/流程模块。
- 道具：笔记、知识卡、流程板。
- 气质：整理、沉淀、结构化。
- 适用：知识库、SOP 服务页、文章封面。

推荐融合：A + C。保留人物识别和专业可信度，用便签、节点和小屏幕表达工具工作流。

## 5. 第二层：IP 设定图要求

设定图不是单张美图，而是一组标准资产。

### 5.1 必要设定

- 正面站姿
- 侧面半身
- 背面或 3/4 角度
- 头像裁切
- 三个表情：冷静、思考、确认
- 三个动作：整理卡片、递交方案、指向流程
- 三个道具：屏幕、便签、节点线
- 主色和辅助色

### 5.2 形象约束

- 头身比例：轻度插画化，不幼态。
- 五官：简洁，但要有清晰表情。
- 服装：简洁中性，可用浅色外套、深色内搭、轻量工作围裙或夹克。
- 标志物：腕部或肩侧可有小型节点灯、便签夹、透明屏幕。
- 颜色：暖白、石墨黑、清绿、蓝青，少量琥珀提示色。

## 6. 第三层：场景图效果图

V1 场景图不做空泛海报，直接绑定系统真实场景。

| 场景 | 画面目标 | 业务用途 |
| --- | --- | --- |
| 首页首屏 | Xenia 站在浅色网格工作台前，旁边有知识、工具、项目、SOP 四个入口 | 公开首页品牌识别 |
| 工具台总览 | Xenia 指向“规划 -> 创作 -> 生成 -> 发布”流程 | 登录后引导 |
| IP 原型工坊 | Xenia 展示草稿图、风格图和提示词预览 | 当前工具说明 |
| 知识库封面 | Xenia 整理笔记、卡片和文章封面 | 文章封面模板 |
| SOP 服务页 | Xenia 把混乱流程整理成清晰流程板 | 企业服务转化 |
| 社媒竖版封面 | Xenia 头像强识别，保留标题区 | 抖音、小红书、视频封面 |

## 8. 系统流程升级建议

建议将当前 IP 原型工坊升级为 7 步。

```text
1. IP 类型
人物 IP / 产品 IP / 内容 IP

2. 立意定义
名称、身份、一句话、目标用户、性格、价值、禁区

3. 参考图输入
简笔草图、风格参考、品牌参考、反向参考

4. 原型生成
输出 4-6 张方向探索图

5. 设定图
正面、侧面、表情、动作、道具、配色

6. 场景效果图
首页、工具台、知识库、SOP 服务、社媒封面

7. 沉淀发布
进入图片画廊，生成后续任务，沉淀到知识库或文章草稿
```

## 9. 验收标准

- 访客能从 IP 判断这是 AI 实践者和工具工作流相关品牌。
- IP 能同时出现在公开首页、工具台、知识库和 SOP 服务页，不违和。
- 角色不幼态、不暗黑、不机甲、不营销号。
- 至少生成一张角色设定图和六张场景图。
- 后续每张图都能追溯到同一套立意、配色、道具和场景规则。
- 产出的提示词能直接复用到当前 IP 原型工坊。
