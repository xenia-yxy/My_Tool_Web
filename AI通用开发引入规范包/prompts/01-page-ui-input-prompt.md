# 页面 UI 输入提示词

用途：当你要让 AI 设计一个页面时，先用这个格式描述。

```text
页面名称：

主任务：

用户角色：

布局：

信息优先级：
P0：
P1：
P2：

交互：

状态：
loading：
empty：
error：
submitting：
success：
permissionDenied：

权限：

样式：

组件库：

不做范围：

特殊硬规则：
```

AI 输出要求：

```text
1. 页面目标
2. 信息架构
3. 布局说明
4. 组件选择
5. 交互规则
6. 状态规则
7. 权限规则
8. 样式与 token
9. 开发注意事项
10. 验收清单
```
