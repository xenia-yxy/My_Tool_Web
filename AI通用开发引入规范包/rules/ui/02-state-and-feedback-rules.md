# 状态与反馈规则

用途：保证每个页面、组件和操作都有完整状态。

---

## 1. 通用状态

每个关键页面至少考虑：

```text
loading
empty
error
submitting
success
permissionDenied
```

---

## 2. 列表页状态

```text
首次加载中：
加载成功：
空数据：
筛选后无结果：
接口失败：
重试中：
分页加载：
权限不足：
```

---

## 3. 表单页状态

```text
初始态：
编辑中：
校验失败：
提交中：
提交成功：
提交失败：
无权限编辑：
```

---

## 4. 操作反馈

```text
普通操作：轻量 toast / message。
危险操作：确认弹窗 + 明确后果。
批量操作：显示影响数量 + 操作结果。
接口失败：显示原因 + 重试入口。
无权限：disabled + 原因说明。
```

---

## 5. 禁止项

```text
不要只写 loading。
不要接口失败后只 console。
不要无权限时只隐藏按钮。
不要提交中还能重复点击。
不要成功后没有反馈。
```
