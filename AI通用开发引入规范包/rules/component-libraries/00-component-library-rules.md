# 组件库使用规则

用途：每次开发 UI 时约束组件库选择和使用。

---

## 1. 一个项目保持一套主组件库

```text
移动端 H5 / 小程序风格：Vant、TDesign Mobile
企业后台：Ant Design、Element Plus、TDesign、Semi、Arco
AI 工具 / 现代 SaaS：shadcn/ui、Radix、Tailwind、Material UI
数据可视化：ECharts、AntV
流程图 / 节点编辑：React Flow
代码编辑：Monaco Editor
```

规则：

```text
1 个主 UI 组件库。
1 套设计 token。
1 套布局规则。
1 套交互规则。
```

可以使用专业辅助库，但边界必须明确。

---

## 2. 组件映射必须先确定

```text
按钮：
表单：
表格：
弹窗：
抽屉：
通知：
上传：
分页：
标签：
空状态：
```

开发前先确定这些组件来自哪里。

---

## 3. 禁止项

```text
不要混用多个同类 UI 库。
不要自造组件库已有成熟组件。
不要直接覆盖组件库深层 CSS。
不要破坏组件库默认可访问性。
不要为了局部页面方便引入另一套同类组件。
```

---

## 4. 二次封装

以下能力建议封装成项目组件：

```text
业务表格
业务筛选区
状态标签
权限按钮
图片上传
详情抽屉
确认操作
空状态
错误重试
```

二次封装必须保留组件库原有状态和可访问性。
